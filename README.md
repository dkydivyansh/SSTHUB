# Run and deploy your AI Studio app

This repository contains the SSTHUB project. It uses a **React** frontend and a **PHP** backend. The `dist` directory serves as the server root.

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/2c3fca84-43e3-4c5a-a143-9811e47eb6ee

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
