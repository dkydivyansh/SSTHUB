# Design Rules

- **No Gradients:** Strictly avoid gradient-based designs (no `bg-gradient`, `radial-gradient`, `linear-gradient`, etc.). Use solid colors only.
- **Creative Typography & Elements:** Play with font design, weights, tracking, and structural elements (borders, layout, spacing, blocks) to create visual interest instead of relying on gradients.

# Copywriting & Language Rules

- **Formal Language:** Use formal, professional terminology. Avoid slang, overly aggressive, or sci-fi/hacker terminology (e.g., do not use "Initialize", "Enter the Grid", "System Override", "Kinetic Layout", "Aggressively loud place"). Use terms like "Open", "Access", "View Schedules", "Explore".
- **Target Audience:** The application is for students of the "Scaler School of Technology". Ensure copy reflects this specific institution.

# Project Architecture Rules

- **Frontend:** Built with React.
- **Backend:** Built with PHP.
- **Server Root:** The `dist` directory (`d:\Projects\SSTHUB\dist`) acts as the server root for the PHP backend. Ensure any production-ready assets and PHP scripts are correctly placed or built into this directory.
